# Contributing

Short version: please don't, and thank you for wanting to.

This repository is a **published snapshot of an internal one**, not a project. Development
happens elsewhere, on a private server, and this copy is synced when the code it mirrors is
deployed. A merged pull request here would be overwritten by the next sync — so accepting
one would waste your work, which is the actual reason for saying no.

Issues are disabled. Pull requests can't be turned off on a public repository, so they
remain possible; they will be closed unread.

## What is worth sending

Two things, by email — **dongliliu0@gmail.com**:

**A security problem.** Please report it privately rather than opening a public pull
request. The authentication model has a known and deliberate limit, described in the README
under *The authentication model, stated plainly* — that one is disclosed, not overlooked.
Anything beyond it is worth knowing about.

**A claim that isn't true.** The README makes specific, checkable assertions about what this
server stores, what it doesn't, and what it is not. If the code doesn't support one of them,
that is the most valuable thing you could tell us, and it will be fixed in the source rather
than papered over here.

## Forking

The licence is [Apache 2.0](LICENSE), and forking is genuinely fine — run your own, change
it, keep the changes. Aeyo's value is the app and the people already in your cart, not this
relay. The name and logo aren't covered by the licence.
